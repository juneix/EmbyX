⚠️ fnOS User Notice

The built-in Webview in fnOS App has issues causing stutter and failing to swipe up/down to switch videos.

Use the PWA app or download the standalone client instead. See the "IP or Domain" format examples.

Address Format Examples
LAN Direct Default port 8096 / 8090 / 5244
10.1.1.3
10.1.1.3:8096
http://10.1.1.3:8096
Domain Default port 443
5nav.eu.org
5nav.eu.org:8920
https://5nav.eu.org:8920

The official demo site requires HTTPS to reach the server. HTTP users are advised to use Lucky reverse proxy, download the APK, or self-host.

PWA App Installed
In your browser use "Add to Home Screen / Install App". Works on Android, iOS, HarmonyOS, Win, Mac and Linux.
Standalone Client Download
Android users can download and install EmbyX.apk. Supports HTTP/HTTPS.
